# 长期接电与充电管理

把手机放在家里长期使用时，先查看该机型是否提供充电上限或旁路供电。厂商、机型和系统版本不同，不能从另一款手机的说明推断当前设备支持。保持散热，避免长时间高温、满电；充电上限只能减缓部分老化因素，不能让电池不老化。

声明 `battery_status_v1` 的 Airtap 客户端可通过 CLI `battery-status` 或 MCP `phone_battery_status` 读取电量、接电类型、状态、温度、电压和电流。读取不点亮屏幕；系统没有提供的数值返回 `null`。`health` 是 Android 的状态枚举，不是剩余容量百分比；`full`、`is_charging` 和电流读数也不能单独证明旁路供电。

Airtap 当前没有通用的停充接口。Android 公共电池接口用于观察，不提供跨机型的物理充电开关。调试工具模拟“未接电”不等于实际断开充电，不能用它作为电池保护。

## 可选智能插座

可将支持远程通断电的智能插座放在墙壁电源与手机充电器之间。AI 可通过手机上的厂商 App 操作，也可使用厂商支持的自动化集成。小米提供[官方 Home Assistant 集成](https://github.com/XiaoMi/ha_xiaomi_home)，经账号授权后控制支持的设备；这种方式需要运行 Home Assistant，不是 Airtap 已提供的直接接入。具体插座、区域、固件和断网定时能力须逐项确认。

持续的充电控制应由规则执行，AI 负责设置、检查和处理异常。例如先评估低于 60% 通电、达到 80% 断电，留出间隔以免反复切换；这只是初始策略，需按设备耗电与在线要求调整，不是已经验证的最佳阈值。

- 两台手机可共用一个智能插座和普通插排，但会同时通断电。初始策略可取“任一台低于 60% 通电，两台都达到 80% 才断电”；电量不同步时会有一台充得更满。希望分别控制时再各用一个插座。明确名称和设备身份，不要连带切断路由器或其他设备。
- 发出命令后检查插座状态，再读取手机是否实际接电；超时先查结果，避免重复切换。
- 断电前设好独立于手机和 AI 会话的恢复供电方式，并实测断网后仍执行。不能只靠即将耗尽电池的手机给自己恢复供电。
- 电量数据过期时停止新的断电动作；高温或异常健康状态交由设备原有保护处理，不用定时规则覆盖保护。
- 优先使用手机厂商已有的充电上限或旁路能力。外部插座断电后手机会消耗电池，仍有充放电循环。

目前仅实现电池观察接口；智能插座接入、阈值控制和无人值守恢复尚未实机验证，也不是普通安装的必需项。

依据：[Android 电池状态](https://developer.android.com/training/monitoring-device-state/battery-monitoring)、[BatteryManager](https://developer.android.com/reference/android/os/BatteryManager)、[Google 充电优化说明](https://support.google.com/pixelphone/answer/6090612)。Google 的具体设置只适用于其列出的 Pixel 设备。
