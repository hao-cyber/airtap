日常使用

连接一次，接着用。

AI 可以在你授权的手机上切换 App，不用逐个重新批准 Airtap。第三方 App 的首次登录、必要协议或系统验证，仍按实际要求处理。

正常断网后会尝试恢复原连接。你可以随时在 App 或通知里停止并解除连接；停止以后，AI 需要新的邀请和你的确认才能再接入。

我的 AI 能用吗？

需要能调用工具、执行网络请求的个人 AI；用截图找位置、点击时，还需要实际看图能力。Muse 与 Instinct 有上面的限定范围实测，其他 AI 的具体产品、模式和版本仍需验证。只能聊天、不能调用工具的窗口还不能接入。

把完整邀请交给你的 AI，让它检查接入要求并实际尝试连接。普通聊天模式不会因为收到邀请就自动获得工具能力。

需要 USB、电脑、插件，或同一个 Wi-Fi 吗？

安装和日常使用无需 USB、常开电脑、额外插件或自建服务器。手机主动通过网络连接公共中继，AI 无需与手机在同一 Wi-Fi。先用能上网的 Wi-Fi 接入；纯移动网络的完整任务仍待独立验收。

开发者也可以部署开源中继，见自行部署说明。

下载和更新怎么操作？

在安卓手机浏览器打开下载的 Airtap.apk。若系统询问，允许该浏览器安装应用，再返回继续。微信等 App 拦截下载时，用菜单里的“在浏览器打开”。安装后打开 Airtap，点击“开始使用”。

本页下载按钮始终提供推荐版本，App 的“设置 → 检查更新”也能找到它。更新直接覆盖安装，保留数据和连接，不要先卸载或清除数据。

进入“无障碍”以后，该点哪里？
  1. 找到“Airtap 手机操作”。有些手机需要先进入“已下载的应用”“已安装的应用”或“已安装的服务”。
  2. 打开“使用 Airtap 手机操作”或“启用服务”，按系统提示确认。
  3. 返回 Airtap，也可以从桌面重新打开。再允许连接通知，App 会继续准备邀请。

开关打不开时，查看受限设置帮助。

提示“受限设置”，开关打不开怎么办？

确认安装包来自本页后，在 Airtap 点击“提示‘受限设置’？” → “打开 Airtap 应用信息”，从右上角“⋮”菜单选择“允许受限制的设置”，按系统提示确认，再返回开启手机操作。

不同手机入口可能不同。没有这个菜单时，先回无障碍列表，点一次“Airtap 手机操作”；若系统显示受限设置提示，关闭后再回应用信息检查。

发了邀请，AI 没接上怎么办？

确认发的是 App 生成的完整邀请，发到能使用工具的私人 AI 对话。只有官网或 GitHub 链接不够。若 AI 只解释步骤，让它按邀请实际完成接入；若该模式没有工具能力，则暂时不能用。

邀请五分钟有效。尚未批准且确认已过期时，再生成新邀请；AI 已申请连接时，继续核对六位数字。连接成功后无需反复发邀请。

原来能用，现在离线或操作超时怎么办？

先让 AI 检查保存的原连接与手机状态。正常断网会尝试重连，息屏也不等于解除连接；不要直接卸载、清数据或重新配对。

需要手机处理时，按 App 提示检查网络、手机操作权限与后台设置。系统强制停止后可能需要重新打开 Airtap；主动“停止并解除”后则需要新邀请。操作超时可能已经执行，AI 应先检查当前画面，避免重复发送或点击。

手机可以放在家里，不随身带着吗？

可以按远程使用来准备：手机保持供电和网络，离开前让 AI 检查这台手机的连接、息屏唤醒和后台表现。需要调整后台设置时，只调整 Airtap。当前没有一键完成所有准备和验证的功能。

短时检查不代表多日无人值守已通过。重启、系统强制停止或要求本人身份验证时，可能仍需在手机上处理。系统要求本人解锁时，本次设备操作不会执行；完成验证后，AI 应重新观察再继续。

可以操作哪些 App？还要逐个授权吗？

Airtap 提供查看屏幕、点击、输入、滑动和切换 App 等通用操作，不以几个演示 App 为限。连接后无需为另一个 App 重新批准 Airtap，但可用程度仍取决于系统、App 界面和 AI 的能力。

App 首次协议、登录和系统权限可能需要准备。AI 应先处理已获授权且允许代办的步骤；确实需要你决定或本人验证时再说明。发送、付费或账号变更也须有对应任务授权，整机接入不代表所有行为都已获准。

支持哪些手机？iPhone 能用吗？

当前为 Android 14+ 公开测试版，主要真机记录来自魅族 Note 16 / Android 15。更多机型、普通用户独立安装、纯移动网络完整任务和多日后台仍待验证。iPhone 和其他设备尚未发布支持版本。

有什么费用？

Airtap 不要求另外购买模型 API 或填写模型密钥。任务仍可能消耗你原有 AI 套餐的额度，公共中继也有运行成本，不承诺永久无限免费。

屏幕内容会经过哪里？

手机与个人 AI 通过 Airtap 的公共中继通信。服务能接触转发的屏幕、界面文字和操作内容，默认不持久化这些内容；目前没有应用层端到端加密。邀请和连接配置只应交给自己的私人 AI。

遇到问题，怎么反馈？

先告诉你的 AI，让它检查并尝试恢复。你也可以授权它整理脱敏故障描述，通过 Airtap 私有反馈提交，不需要 GitHub 账号。报告私有保存 30 天；手机“设置 → 问题反馈”可查看状态和删除。

也可以去GitHub Issues。那里是公开的，请勿附上邀请、凭据或含私人内容的截图。
